# Vendor Management System

## Start the prototype

From this folder, run:

```bash
npm start
```

This starts the backend at http://localhost:5001, starts the frontend at http://127.0.0.1:5173, and opens the frontend automatically in Google Chrome when it is ready.

On macOS, you can also double-click `Start Vendor Management.command`.

## Other commands

```bash
npm run seed
npm run build
```
